# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate in language and tone
- Focusing on what is best for the community and users
- Giving and receiving feedback constructively

Examples of unacceptable behavior include:

- Harassment, discrimination, or personal attacks
- Publishing others' private information without explicit permission
- Trolling, insulting comments, or deliberate intimidation

## Enforcement

Project maintainers are responsible for clarifying standards and enforcing this Code of Conduct. They may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with this Code of Conduct.

## Reporting

To report Code of Conduct violations, contact the maintainers via a GitHub Security Advisory (preferred for private reporting) or by opening a private communication channel with the maintainer.
