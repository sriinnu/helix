# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities via GitHub Security Advisories (preferred):

1. Go to the repository's "Security" tab.
2. Select "Advisories".
3. Click "Report a vulnerability".

If GitHub Advisories are not available, open a private message to the maintainer with a minimal reproduction and impact description.

## Supported Versions

Security fixes are applied to the latest `main` branch first. Backports are best-effort.
